# Product task instructions

- Build the product described in `SPEC.md`; this is a greenfield implementation.
- Linux and Node.js 24 are the target. Use only Node's standard library.
- You may change any file and add tests. The final evaluator uses its own
  pristine black-box checks, so do not weaken the supplied checks.
- Run `npm test` and an end-to-end smoke test before finishing.
- Keep runtime data outside the source tree by honoring `DATA_FILE`.
- Finish with a concise description of the working product and verification.
